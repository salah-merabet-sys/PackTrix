# ============================================================

# DEMO MODE  (zero extra packages needed)
# ----------------------------------------
# All four commands — scan, sniff, analyze, dashboard — run
# on the Python standard library alone with realistic simulated
# data.  No root, no Scapy, no third-party packages required.
#
# Standard library modules used:
#   argparse, socket, ipaddress, re, os, sys, shutil, signal,
#   threading, queue, select, tty, termios, csv, json, logging,
#   logging.handlers, datetime, dataclasses, pathlib, textwrap,
#   importlib, pkgutil, collections, concurrent.futures
#
# LIVE MODE  (optional extras)
# ----------------------------------------
# Install these to capture real traffic and enumerate NICs:
#
#   pip install scapy netifaces
#   sudo packtrix sniff eth0
#   sudo packtrix scan 192.168.1.0/24 --ports
#
# Or use the packaged extras:
#
#   pip install "packtrix[live]"    # scapy + netifaces
#   pip install "packtrix[dev]"     # testing + linting tools
#   pip install "packtrix[all]"     # everything
#
# ── Live capture (optional) ───────────────────────────────────────────────────
